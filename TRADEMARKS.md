# MaterialScope Name and Logo Policy

"MaterialScope" is the name of this project. It is **not** a registered
trademark, and this document does not claim registered-trademark rights.
This is a modest, factual usage policy.

The AGPL-3.0-only license grants copyright permissions for the software.
It does not grant permission to use the MaterialScope name or logo to
imply that a copy, fork, or derivative work is the official project, is
endorsed by it, or is sponsored by its maintainer.

## What is allowed

- Truthful, nominative references such as "based on MaterialScope",
  "forked from MaterialScope", "compatible with MaterialScope", or
  "uses MaterialScope" — when accurate.
- Referring to the upstream project by name in documentation,
  changelogs, comparisons, and attribution notices.

## What we ask

- Give forks and derivative distributions a distinct product/project
  name and branding, so users are not confused about which software they
  are running.
- Do not use the MaterialScope name or logo in a way that falsely
  suggests official status, endorsement, or sponsorship — for example,
  distributing a modified build under the unqualified name
  "MaterialScope", or using the logo to present your fork as the
  official project.
- For uses beyond nominative reference (for example, an official-looking
  distribution or service under the MaterialScope name), contact the
  repository owner through the project repository first.

This policy is intentionally narrow: it protects users from confusion
about origin while leaving AGPL rights — and honest references to the
project — fully intact.
