MaterialScope's public license has changed once. This document records
the transition honestly.

remains under its own terms and is not relicensed.

## Git history

Git history is intentionally preserved. Old commits, tags, and revisions
that carried the MIT License have not been rewritten, squashed, deleted,
or hidden. Checking out a pre-transition commit gives you the
MIT-licensed code exactly as it was published.
