Why MaterialScope

Stop stitching lab setups together with spreadsheets.

Vendor software, Excel, plotting tools, reference databases and reporting documents usually live in separate worlds. MaterialScope keeps your data, processing choices, comparisons and outputs in a single project workflow.

One import pipeline

Open CSV, TXT, TSV, XLSX and XLS files from any instrument. Column mapping and data-quality warnings are surfaced before you analyze.

Modality-aware processing

Each technique gets a workflow tuned to its conventions — thermal analysis, spectral processing, or diffraction handling — with sensible units and axis roles built in.

Interactive visualization

Inspect results in interactive plots with scientific styling — clean axes, correct units, annotations, and figures ready for the lab notebook, slide deck or paper.

Run comparison

Overlay samples, heating rates or replicates side by side. Compare curves from different days or instruments without rebuilding the figure from scratch.

Report-ready export

Export figures, processed data and structured reports — data tables, figure panels, captions and analysis summary in one artifact set.

Reproducible by design

Source data, processing decisions and outputs stay connected in one project, so a result can be revisited, understood and re-run — not re-created.

Techniques

Six characterization methods. One language.

From thermal transitions to diffraction patterns, MaterialScope speaks each technique's conventions so your plots and reports stay consistent.

Thermal

DSC

Differential scanning calorimetry — glass transitions, melting and crystallization, with multi-rate heating and thermal-event analysis.

Thermal

TGA

Thermogravimetric analysis — mass-loss steps, decomposition and stability profiles, with derivative curves for overlapping events.

Thermal

DTA

Differential thermal analysis — endothermic and exothermic events at controlled heating rates, ready for sample-level comparison.

Spectral

FTIR

Fourier-transform infrared spectroscopy — transmittance and absorbance spectra, background handling and functional-group band review.

Spectral

Raman

Raman spectroscopy — spectral processing, peak identification and comparison against expected vibrational signatures.

Diffraction

XRD

X-ray diffraction — pattern processing, peak analysis and reference-pattern comparison to support phase identification.

Get started

Running locally takes minutes.

MaterialScope is a standard Python package. Clone the repo, install it in a virtual environment, and launch the app.

  • Python 3.11+ with pip
  • Dash + FastAPI + Plotly — the app opens in your browser at 127.0.0.1:8050
  • MIT licensed — free to use, modify and share
View the repository
terminal 
# clone and set up the environment
git clone https://github.com/utkuvibing/MaterialScope.git
cd MaterialScope
python -m venv .venv
# activate: Windows PowerShell
.\.venv\Scripts\Activate.ps1
# activate: macOS / Linux
source .venv/bin/activate

# install and run
pip install -e .
python -m dash_app.server
# → http://127.0.0.1:8050

A tool for engineers and researchers — not a substitute for expertise. MaterialScope is an evolving research and engineering project. Its analysis outputs support scientific workflows but do not replace expert validation, particularly for qualitative spectral and XRD interpretation.
