01 — Why MaterialScope

One experiment.
Five disconnected tools.

Vendor export utilities, a spreadsheet for cleaning, a plotting tool for figures, a database for reference data, a separate document for the report. The science is continuous — the tooling around it usually isn’t.

MaterialScope keeps import, processing, comparison, and export inside a single project workspace, so every figure stays traceable to the raw measurement it came from.

02 — How it works

A workflow that mirrors the bench.

  1. 01

    Import

    Bring in CSV, TXT, TSV, XLSX, or XLS measurement files from any instrument vendor.

  2. 02

    Review

    Check column mapping, units, and data-quality warnings before any analysis runs.

  3. 03

    Analyze

    Run the matching workflow — thermal events, spectral bands, or diffraction patterns.

  4. 04

    Compare

    Overlay runs and samples in a shared workspace with aligned axes and styling.

  5. 05

    Export

    Take away figures, tabulated results, and structured report outputs — linked to their history.

03 — Capabilities

Engineered around characterization data.

Guided import with a quality gate

Column mapping, unit detection, and quality checks run before analysis — so a malformed scan fails loudly instead of quietly skewing your results.

core/data_io · preview · warnings

Analysis you can adjust and audit

Baseline correction, peak analysis and deconvolution, and Kissinger kinetics for multi-rate thermal data — each step exposed, not hidden in a black box.

scipy · pybaselines · lmfit

Comparison in one workspace

Stack DSC scans, TGA ramps, spectra, or XRD patterns from multiple runs on shared axes — then capture a curated figure straight from the comparison view.

Plotly · figure capture

Outputs that remember their source

PNG/SVG figures, CSV/XLSX results, and structured DOCX/PDF reports leave with the project’s processing history attached — reproducible months later.

provenance · reportlab · python-docx

04 — Modalities

Six techniques, one data model.

Each modality gets its own workflow, plot conventions, and review tools — on the same import, comparison, and export pipeline. These traces come from the project’s real sample datasets.

05 — Who it’s for

Built with lab workflows in mind.

  • Research teams

    Materials science & engineering groups running multi-technique campaigns — from synthesis screening to failure analysis.

  • QC & R&D laboratories

    Quality control and development labs standardizing characterization routines across samples, shifts, and instruments.

  • Graduate workflows

    Thesis projects where reproducibility and publication-quality figures are not optional extras.

  • Testing groups

    Industrial material testing teams comparing runs across conditions, batches, and suppliers.
