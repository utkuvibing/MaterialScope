# Contributing

MaterialScope is licensed under AGPL-3.0-only and may also be offered
under a separate proprietary/commercial license (dual licensing; see
[COMMERCIAL-LICENSING.md](COMMERCIAL-LICENSING.md)).

## Contribution policy

- Contributions are welcome only under this documented policy.
- Because the project may be dual-licensed, accepting external code
  contributions requires clarity about contributor rights: the project
  owner intends to establish a proper contributor license agreement
  (CLA) or an equivalent contributor-rights mechanism before merging
  outside code contributions.
- Until that mechanism is in place, external code contributions whose
  terms would need to support future proprietary relicensing should not
  be merged.
- Bug reports, documentation suggestions, and issue discussion are
  welcome via the repository's issue tracker.

No contributor agreement exists yet. Nothing in this document or
repository transfers or grants contributor rights beyond the AGPL terms
under which a contribution is submitted.
